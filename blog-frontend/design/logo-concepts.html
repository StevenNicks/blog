Cuatro marcas para elegir, no una sola respuesta correcta

Cuatro conceptos de logo dibujados a mano en SVG, pensados para calzar con el sistema visual que ya tiene la app (acento lima sobre superficies casi negras, esquinas suaves, tipografía Inter/Raleway). Cada uno funciona como marca sola (favicon, avatar, sidebar colapsado) y como lockup completo con el nombre. El marcado recomendado es una sugerencia, no un veredicto — la decisión es tuya.

Página doblada
